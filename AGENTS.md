> **Трек №2:** «О!дин запрос» (AI-агент для умного поиска и бронирования отелей).

## 1. Главные инженерные принципы (Стандарты Островка)

### Запрет «AI-слопа»

1. **Никаких галлюцинаций цен и наличия:** LLM используется **исключительно** для извлечения интентов и слотов (Intent & Slot Extraction).
2. **Строгий детерминизм:**
   - Фильтрация отелей, проверка правил (проживание с питомцами, дистанция до подъемников/пляжей, звездность) выполняется кодом через Pydantic.
   - Математика чека (ночи × цена номера + сбор за собаку + курортный сбор) считается **строго кодом** в `receipt_calc.py`.
   - Запрещено просить модель сложить числа или рассчитать итоговую сумму бронирования!
3. **State Machine вместо хаотичных ReAct-циклов:** Агентный пайплайн управляется детерминированным графом состояний (LangGraph).
4. **Отказоустойчивость ($0 Budget & Pitch-Safe):**
   - Трёхуровневый каскад: `Gemini 2.0/3.x Flash` ➔ `Gemini 1.5 Flash-8b` ➔ `Deterministic Mock Slot Extractor`.
   - Если API Google недоступен, квота 429 исчерпана или нет интернета — локальный детерминированный экстрактор слотов гарантирует 100% успех демо перед жюри.

## 2. Архитектура фронтенда: Feature-Sliced Design (FSD)

Фронтенд строго структурирован по методологии FSD (Next.js App Router).

### Иерархия слоев (сверху вниз):

1. `app/` — корневая инициализация приложения, роутинг Next.js, провайдеры, глобальные стили (`globals.css`).
2. `widgets/` — крупные самостоятельные блоки интерфейса:
   - `ChatConcierge` (левая колонка 420px: поток мыслей, чат, голосовой ввод, чипсы).
   - `HotelCanvas` (правая колонка 1020px / flex-1: шапка выдачи, сетка отелей).
3. `features/` — пользовательские интерактивные сценарии:
   - `voice-input` (голосовой ввод через Web Speech API).
   - `quick-chips` (чипсы быстрых уточнений Disambiguation).
   - `book-room` (модалка бронирования номера с прозрачным чеком).
4. `entities/` — бизнес-сущности предметной области:
   - `hotel` (карточка `HotelCard`, бейдж `MatchScore`, типы `Hotel`).
   - `message` (пузырь сообщения `ChatMessage`).
   - `thought` (элемент стрима мыслей `ThoughtStream`).
5. `shared/` — переиспользуемый инфраструктурный код:
   - `ui/` — дизайн-система (shadcn/ui примитивы).
   - `api/` — хук `useChatStream` (SSE-клиент с поддержкой AbortController).
   - `lib/` — утилиты (`cn`, форматирование цен).
   - `config/` — дизайн-токены и конфигурация.

### 🛡️ Золотое правило: Public API (Barrel `index.ts`)

- Каждый слайс (`entities/hotel`, `features/voice-input` и т.д.) обязан иметь файл `index.ts`.
- Внешние импорты разрешены **только** через Public API:

  ```typescript
  // ✅ ПРАВИЛЬНО:
  import { HotelCard, type Hotel } from "@/entities/hotel";
  import { VoiceInputButton } from "@/features/voice-input";

  // ❌ ЗАПРЕЩЕНО (будет остановлено линтером):
  import { HotelCard } from "@/entities/hotel/ui/HotelCard";
  import { VoiceInputButton } from "@/features/voice-input/ui/VoiceInputButton";
  ```

- **Запрет кросс-импортов:** Модули внутри `features/` не могут импортировать другие модули из `features/`. Модули внутри `entities/` не могут импортировать другие `entities/`.
- Настроен линтер `eslint-plugin-boundaries`, гарантирующий соблюдение этих правил в CI и локально.

## 3. Дизайн-система: Dark Swiss Minimalist (Без хардкода HEX)

- **Строго запрещено** хардкодить цвета через HEX в JSX (`className="bg-[#0D0E11] text-[#2DD4BF]"` — ЗАПРЕЩЕНО!).
- Все токены вынесены в CSS-переменные темы в `src/app/globals.css`:
  - Фон страницы: `bg-background` (`#0D0E11`)
  - Карточки и панели: `bg-card` (`#16181D`)
  - Бордеры и разделители: `border-border` (`#242731`)
  - Акцентный цвет (Teal): `text-primary`, `bg-primary` (`#2DD4BF`)
  - Основной текст: `text-foreground` (`#F4F4F6`)
  - Второстепенный текст: `text-muted-foreground` (`#8E92A0`)
- Интерфейс оптимизирован под сплит-экран 1440x900 (десктоп хакатона).

## 4. Контракт Server-Sent Events (SSE) `/api/chat/stream`

Эндпоинт стримит события в формате SSE:

- `event: thought`: ход мыслей агента в реальном времени:
  ```json
  { "step": "search", "text": "Ищу отели в Красной Поляне с бассейном..." }
  ```
- `event: token`: потоковый чанк ответа консьержа:
  ```json
  { "content": "Я нашел отели, подходящие под ваш запрос." }
  ```
- `event: widget`: структурированный JSON для отображения виджетов на канвасе:
  ```json
  {
    "type": "hotel_grid",
    "hotels": [...],
    "disambiguation_chips": ["Дешевле 10 000 ₽", "С завтраком", "У подъемника"]
  }
  ```
- `event: done`: сигнал завершения генерации:
  ```json
  { "status": "ok" }
  ```

## 5. Запуск и скрипты проекта

В корневом `package.json` настроены команды:

| Команда                   | Что делает                                                    |
| ------------------------- | ------------------------------------------------------------- |
| `npm run dev`             | **Основная команда:** Запуск фронтенда и бэкенда в hot-reload |
| `npm run dev:static-back` | Запуск фронтенда в hot-reload, бэкенда — в статичном режиме   |
| `npm run dev:front`       | Запуск только фронтенда (Next.js на порту 3000)               |
| `npm run dev:back`        | Запуск только бэкенда (FastAPI на порту 8000 с `--reload`)    |
| `npm run lint`            | Проверка линтерами (ESLint + FSD Boundaries)                  |
| `npm run test`            | Запуск тестов Vitest (фронт) и Pytest (бэк)                   |
| `npm run build`           | Проверка продакшн сборки фронтенда                            |

## 6. Памятка для будущих сессий и агентов

- При добавлении новых компонентов строго размещайте их в соответствующем слое FSD (`widgets`, `features`, `entities`, `shared`) и не забывайте обновлять `index.ts`.
- При модификации поисковой логики используйте модуль `backend/app/services/hotel_search_adapter.py`.
- Всегда запускайте `npm run lint` и `npm run test` перед фиксацией изменений.
